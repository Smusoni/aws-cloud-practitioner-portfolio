# Concepts Demonstrated (Exam Mapping)

This project heavily reinforces core competencies within the Cloud Technology and Services domain (34% of the CLF-C02 exam):

* **Elastic Compute Cloud (EC2):** Understanding how to provision, configure, and automate resizable compute capacity in the cloud.
* **Stateful Firewalls (Security Groups):** Demonstrating that Security Groups control inbound and outbound traffic at the instance level. Explicitly allowing inbound Port 80 (HTTP) traffic while recognizing that returning outbound traffic is automatically permitted due to its stateful nature.
* **User Data Automation:** Utilizing bootstrapping shell scripts to install core software packages (Apache/`httpd`) and customize files immediately at launch without needing manual SSH configuration.
