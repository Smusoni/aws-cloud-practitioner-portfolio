# Cost Notes — Food Truck Menu API

## What This Costs You
Effectively $0 at a food truck's traffic. You're billed only per API request and per Lambda run — both tiny.

## Free Tier
API Gateway includes 1 million HTTP API calls per month free for the first year. Lambda includes 1 million free requests per month always. A food truck's scans stay far inside both.

## Cost Controls
- Pay-per-use on both services — no cost when no one is scanning.
- No server running in the background to pay for.
