# Concepts Demonstrated (Exam Mapping)

This project directly proves core competencies required for the AWS Certified Cloud Practitioner (CLF-C02) exam framework:

* **Serverless Architecture**: Designing with high-availability, auto-scaling services that require no underlying OS management (Lambda, API Gateway).
* **Database Selection**: Utilizing a NoSQL key-value store (DynamoDB) purposefully built for single-digit millisecond performance and flexible data attributes.
* **Security & Governance**: Enforcing the Principle of Least Privilege by building specific IAM Execution Roles so the Lambda functions only have rights to read/write to their designated database table.
* **Cloud Monitoring**: Leveraging CloudWatch for real-time observability and logging of backend application logic.
