# Concepts Demonstrated — Appointment Reminders (SNS)

| Skill / Service | How it was applied |
|---|---|
| Amazon SNS | Created a topic and sent a notification to subscribers |
| Publish / subscribe model | One published message delivered to all subscribers |
| Subscriptions | Subscribed an email endpoint and confirmed it |
| Decoupling | The sender doesn't need to know each recipient individually |
| Notifications | Delivered an automated email reminder |
