# Concepts Demonstrated — Order Queue (SQS)

| Skill / Service | How it was applied |
|---|---|
| Amazon SQS | Created a queue, sent messages, and received them |
| Message queues | Held orders in line until they could be processed |
| Decoupling | Separated order intake from order processing |
| Reliability | Ensured orders aren't lost during traffic bursts |
| SNS vs SQS | SQS is a queue pulled by workers; SNS broadcasts to many subscribers |
