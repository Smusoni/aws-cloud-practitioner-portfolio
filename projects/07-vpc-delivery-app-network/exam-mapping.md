# Concepts Demonstrated — Cloud Network (VPC)

| Skill / Service | How it was applied |
|---|---|
| Amazon VPC | Created a private, isolated network in AWS |
| Subnets | Set up public and private subnets within the VPC |
| CIDR ranges | Used a 10.0.0.0/16 VPC range divided into subnets |
| Internet Gateway | Attached a gateway giving the public subnet internet access |
| Route tables | Configured routing so only the public subnet reaches the internet |
| Public vs private subnets | Demonstrated that a subnet is "public" because of its route to the internet gateway |
| Network security design | Separated internet-facing resources from protected ones |
