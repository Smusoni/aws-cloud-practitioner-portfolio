# Cost Notes — Create a Homework Tracker Database with DynamoDB

## Expected Cost
> Effectively $0 for this project. A handful of small items in on-demand mode costs a tiny fraction of a cent.

## Free Tier Assumptions
> DynamoDB has an always-free tier (25 GB storage and a generous amount of read/write capacity per month). A few homework records is far under that.
## Cost Controls
> Use on-demand capacity so you only pay per request
> Delete the table when done
