# Concepts Demonstrated — Cloud Server (EC2)

| Skill / Service | How it was applied |
|---|---|
| Amazon EC2 | Launched and connected to a Linux virtual server |
| AMI | Started the server from an Amazon Linux image |
| Instance types | Chose a free-tier eligible t2/t3.micro |
| Security groups | Configured the firewall controlling access to port 22 (SSH) |
| Key pairs | Created a secure login credential |
| EC2 Instance Connect | Connected to the server securely through the browser |
| Cost discipline | Terminated the instance after verification to stop hourly charges |
